# Form Validation Project

A simple and responsive **Contact Form Validation** project built using **HTML, CSS, and JavaScript**.
This project validates user inputs in real-time and displays error messages dynamically.

---

## 🚀 Features

* ✅ Full Name Validation
* ✅ Phone Number Validation
* ✅ Email Validation
* ✅ Message Length Validation
* ✅ Real-time Error Handling
* ✅ Success Icons for Valid Inputs
* ✅ Responsive UI Design
* ✅ Clean and Modern Interface

---

## ⚙️ Validation Rules

### 👤 Name Validation

* Name field should not be empty
* User must enter full name

### 📞 Phone Validation

* Phone number must contain exactly 10 digits
* Only numeric values are allowed

### 📧 Email Validation

* Email field cannot be empty
* Checks for valid Gmail format

### 💬 Message Validation

* Message should contain at least 30 characters
